# Worked example on every question

## Goal

Учебник печатает образец выполнения над упражнением («Примерен образец», «Работете по модела»), а приложение показывает по одному вопросу за раз, без заголовка упражнения. Учащийся видел только формулировку задания и не видел, какой формы ждут ответ. Образец должен стоять под заданием на каждом вопросе.

## Overview

### Context

- Учебник: `documents/lessons/lesson-1.md:236` — «Примерен образец: Емилия Иванова е студентка. Тя е от България. Говори български, английски и испански.» Аналогично `lesson-2.md:217,236`, `lesson-6.md:176`, `lesson-7.md:161,212,252`.
- В приложении режим `profile_build` («Расскажи о человеке») собран как раз из этого упражнения, но образца не показывал.

### Current State (до задачи)

- `Mode.desc` передавался в движки как `prompt` и рисовался `TaskPrompt` над вопросом — на каждом вопросе, у всех 11 движков.
- Образца выполнения в модели данных не было вовсе.

### Constraints

- Образец обязателен у всех 232 режимов: поле делаем required, чтобы `tsc` ловил пропуск.
- Два языка интерфейса (ru/uk), поэтому `Localized<string>`.
- Текст образца — проза, а не строка `words[]`: без пробела перед знаком препинания.
- Образец парадигмы не должен раскрывать ответ вопроса, который может выпасть следом.

## Solution

1. `Mode.example` в `src/types.ts` — есть у всех режимов, кроме `paradigm`.
2. `TaskPrompt` принимает `example` и печатает вторую строку под инструкцией; ключ `modelLabel` в обоих словарях.
3. Во всех движках — проп `example`, дальше в `TaskPrompt`; в `App.tsx` — `example={L(currentMode.example)}`.
4. Образцы для 224 режимов: где урок печатает модель — берём её, иначе пишем типичный элемент режима. У 8 парадигм текстового образца нет: движок сам подставляет форму 1 лица и метит её словом «пример».
5. `scripts/examples.ts`: непустые ru+uk, образец не копия `desc`, стрелка вне `build`, нет пробела перед знаком, у `paradigm` образца нет вовсе.
